# The Known World

An unofficial 3D atlas of Westeros and Essos. Read `docs/spec.md` and the module
contract before editing. The source brief is the standalone final project section
of Alvaro's personal Notion parent, not its Explore brainstorm list.

- Preserve actual 3D exploration of both continents. Search, labels and details
  must select the same geographic data used by the renderer.
- Use native browser modules and original UI. No runtime dependencies, account,
  backend, analytics, paid service or external tile/API request is required.
- Every reused geometry/data/artifact needs explicit provenance and applicable
  permission recorded in `docs/attribution.md`. A public repository alone does
  not establish an asset license. Keep required notices with redistributed data.
- Explain stylization and approximate coordinates. Do not present procedural
  elevations as canonical measurements or claim a complete fictional planet.
- Keyboard, touch, pointer, responsive states, reduced motion, WebGL failure and
  context loss/restoration belong to the product. Keep navigation bounded and
  preserve unrelated browser storage.
- Use `apply_patch`. Keep shared module contracts stable across owners. No
  dependency install or local app build while Storage Guard fails.
- Run focused pure/source checks and `git diff --check`. User AGENTS.md section 7
  requires explicit approval for browser/dev-server checks. Static/VM checks,
  hosted source delivery and rendered browser acceptance are separate proof.
- The active goal authorizes its dedicated personal GitHub repository and Vercel
  publication. Record exact source/deployment proof in `docs/results/` and keep
  the full all-project goal active until its actual requirements are achieved.
